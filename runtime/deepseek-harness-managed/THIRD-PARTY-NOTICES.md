# DeepSeek Harness Managed Runtime Third-Party Notices

This runtime redistributes the production npm dependency closure recorded in
`package-lock.json`. Package license files published in npm tarballs are kept
inside `node_modules`.

## Primary component

`@deepseek-ai/dsh@0.1.0-rc.6` and the `@deepseek-ai/dsh-*` packages are
copyright 2026 DeepSeek and distributed under the MIT License. Source:
https://github.com/deepseek-ai/deepseek-harness

The complete resolved package names, versions, registry integrity hashes, and
declared licenses are recorded in the lockfile. Phase 0 verification rejects an
installed package outside that production lock closure.
